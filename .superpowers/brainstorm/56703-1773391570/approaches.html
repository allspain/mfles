3 Layout Approaches for the All-Teams Page

Each opens as a full browser tab from the extension icon. Which feels right?

A

Vertical Squad Cards

All squads listed as tall cards down the page. Each card shows the squad name, current OVR, the optimizer's pick with its OVR, and 5 alternatives — all visible at once without any clicking. Apply button on each row.

FC Example · Current OVR: 847
★ BEST Optimizer Pick OVR 871 Apply
Alt 1 Swap Vargas → Diaz OVR 868 Apply
Alt 2 Swap Chen → Park OVR 865 Apply

Pros

  • Everything visible at once
  • No extra clicks

Cons

  • Long scroll with many squads
B

Squad Grid + Expandable Detail

Squads shown as compact summary cards in a grid (2-3 per row), each showing current OVR and best possible OVR. Click a squad card to expand a detail panel below showing all 6 lineup options.

Pros

  • Compact overview of all squads
  • Easy to compare across clubs

Cons

  • Extra click to see options
C

Tabbed by Club

Top-level tabs, one per club. Active tab shows all squads for that club with full lineup options. Good if you have many clubs and want focused per-club workflow.
